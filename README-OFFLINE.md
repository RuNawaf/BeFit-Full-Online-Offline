# BeFit — تدريب المقابلات محليًا

**إعداد: Nawaf Almudahi**

BeFit يساعد الطلاب وحديثي التخرج على مراجعة إجاباتهم للمقابلات السلوكية: يستقبل تسجيلًا صوتيًا، يحوّله إلى نص، ثم يقترح تنظيم الإجابة وفق STAR-L وملاحظة وسؤال متابعة. يمكن تعديل النص والنتيجة وتنزيلها. هذا تدريب وليس تقييمًا للقبول.

## الموديلات
- **Whisper Small** عن طريق `faster-whisper`: تفريغ الصوت إلى نص محليًا من `models/whisper-small`.
- **Qwen 2.5 3B** عن طريق Ollama: اقتراح مراجعة STAR-L من النص محليًا. ملف الموديل `models/qwen2.5-3b.gguf` موجود داخل الحزمة، و`Modelfile` يحتفظ بإعدادات وترخيص النموذج.

## المتطلبات
- Windows 10/11 بنظام 64-bit.
- Python 3.13 بنظام 64-bit مع pip، وNode.js حديث يدعم `fetch` (Node 20 أو أحدث)، وOllama مثبّتة قبل اختبار إغلاق الواي فاي.
- المساحة المطلوبة بعد فك الضغط وتجهيز البرنامج والموديلات لا تقل عن 6 GB إضافية؛ وقد تحتاج مساحة أكبر لبرنامج Ollama. يفضّل توفر 16 GB RAM.
- مجلد `wheels` يحتوي نسخ حزم Python المجرّبة لـWindows 64-bit مع Python 3.13 فقط؛ على نظام أو إصدار Python آخر قد تحتاج تنزيل حزم ملائمة مسبقًا. النماذج موجودة داخل الحزمة.

## التجهيز مرة واحدة
بعد فك الضغط، افتح PowerShell داخل مجلد BeFit، ثم:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-index --find-links=./wheels -r requirements-lock.txt
ollama create befit-qwen:3b -f Modelfile
```

يلزم تشغيل Ollama قبل أمر `ollama create`؛ إذا لم يكن قيد التشغيل، افتحه من قائمة Start. قد يستغرق استيراد الموديل عدة دقائق ويحتاج مساحة إضافية. اسم الموديل المخصص للتطبيق هو `befit-qwen:3b`.

## تشغيل التطبيق

```powershell
npm start
```

افتح `http://127.0.0.1:3001/offline` في Chrome أو Edge، واترك PowerShell وOllama شغالين. إذا كان المنفذ 3001 مستخدمًا، أوقف البرنامج الذي يستخدمه أو شغّل BeFit على منفذ آخر:

```powershell
$env:PORT = '3003'
npm start
```

ثم افتح `http://127.0.0.1:3003/offline`. يطلب المتصفح إذن الميكروفون عند التسجيل؛ يمكن اختيار ملف صوتي بدلًا منه. بعد اكتمال التجهيز، يمكن إيقاف Wi-Fi وتجربة التسجيل والتفريغ والتحليل. لا تحتاج مفاتيح API في نسخة المسابقة. لا تُحفظ التسجيلات على الخادم كملفات؛ تُعالج في الذاكرة. تنزيل المراجعة إلى ملف اختياري.

## الاستخدام
1. اضغط «ابدأ التدريب» واختر سؤالًا.
2. سجّل الإجابة أو اختر ملفًا صوتيًا (حتى 12 MB)، وانتظر تفريغها.
3. صحّح النص عند الحاجة واضغط «حلّل إجابتي».
4. راجع نتيجة STAR-L والملاحظة وسؤال المتابعة، وعدّلها أو نزّلها. عند التنبيه إلى إجابة غير مرتبطة، تقدر تصححها أو تكمل للمراجعة.
5. حذف التسجيل من الصفحة يحذف معه النص والمراجعة المرتبطة بهما.

## وين يخرب؟
- Whisper قد يخطئ في اللهجات والأسماء ومع الضوضاء أو التسجيل الضعيف، وقد يتوهم كلامًا في الصوت غير الواضح؛ لذلك النص قابل للتصحيح. اختبرنا مثالًا عربيًا محليًا وظهرت بعض الأخطاء.
- Qwen نموذج صغير، وقد يخلط بين المهمة والتصرف أو يكرر التصنيف، ويخطئ في تحديد مدى ارتباط الإجابة بالسؤال؛ لذلك يمكن تعديل الاقتراحات وتجاوز تنبيه الارتباط. لا يعتمد عليه لإثبات وقائع أو تقييم القبول.
- التسجيل الصامت أو الملف التالف قد لا ينتج نصًا. يقدم التطبيق رسالة واضحة؛ التحميل والمعالجة قد يستغرقان وقتًا على المعالج.
- الملفات الكبيرة فوق 12 MB مرفوضة. ذاكرة الجهاز وسرعته تؤثران في مدة المعالجة.

## الحقوق
Qwen 2.5 3B يخضع لـQwen RESEARCH LICENSE AGREEMENT؛ النص مرفق في `Modelfile` والإشعار في `NOTICE.txt`. موديل Whisper المرفق وfaster-whisper وحزم Python لها تراخيصها الواردة مع المصدر أو الحزم. المشروع تجربة تدريبية، وليس مرتبطًا أو معتمدًا من أي جهة توظيف.


## الاستنساخ من GitHub

الموديلات الكبيرة مخزّنة باستخدام Git LFS. ثبّت Git LFS ثم استخدم:

```powershell
git lfs install
git clone https://github.com/RuNawaf/BeFit.git
cd BeFit
git lfs pull
```

استخدم الاستنساخ مع Git LFS، لأن زر Download ZIP في GitHub قد يعطي ملفات مؤشرات بدل الموديلات الفعلية. بعد اكتمال التنزيل، اتبع خطوات التجهيز أعلاه.
